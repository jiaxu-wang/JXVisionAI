人脸识别 · 触发类型

勾选后才会写入告警记录；需先在人脸库录入人员。

勾选后在画框与告警中附带性别、年龄（需 models/buffalo_l/genderage.onnx）。

车牌识别 · 触发类型

勾选后才会写入告警记录；需先在车牌库录入号码。与专模「车牌检测」（仅颜色）二选一时优先本项（OCR+库）。

疲劳驾驶 · DMS

仅驾驶室正脸（建议红外）。路侧/大场景会判定不支持，不告警。辅助告警，非司法鉴定。

流预览

ONVIF 发现与接入

扫描局域网 ONVIF 设备，或手动填写 IP。检测通过（状态正常）后选择码流 Profile，一键加入监控（写入 RTSP，无需再点「保存配置」）。 海康等请填集成协议里的 ONVIF 用户（非网页登录用户亦可）。若本机开了 HTTP 代理，服务会绕过代理直连摄像机。

通道配置

序号 通道 ID 别名 在线状态 操作

同一 SIP 用户下可配置多个通道；视频通道 ID 为 20 位，第 11–13 位类型码须为 131/132（海康校验）；137 是语音输出通道。新增时默认按 131 自动分配。
