RTSP直连

填写可拉流的 rtsp:// / rtsps:// 地址。保存后接入平台并定时探测在线；离线不可预览。点「接入AI分析」后才会进入检测配置。

修改地址后需「保存」并重启服务生效。

ONVIF 接入

发现或手填 IP 探测设备 → 选 Profile 加入平台。可预览（需在线）、复制 HLS、改名称、刷新 RTSP、对讲、删除。点「接入AI分析」后才会进入检测配置。

摄像机「上级平台」填 SIP 服务器 ID、域、对外地址和 SIP 服务器端口。监听地址不填到设备；对外地址必须是摄像机可达的 IP。

媒体收流（Invite / ZLM）

只用于点播 SDP，不填到摄像机 SIP 表单。每路通道从范围内占用一个 UDP 端口，可同时多路收流。

设备列表

点「新建」填写 SIP 用户与密码，用户名/认证 ID 自动分配。预览和接入分析在「通道」里按通道操作（预览不等于分析）。「复制参数」用于摄像机上级平台配置。
